## Interpretation

The data pipeline is now unblocked for historical machinery qualification, but the dry-run replay qualification gate is blocked.

The likely issue is replay-window scoping: the exported historical panels include the full indicator lookback, and the replay/backtest path appears to evaluate the broad lookback-derived panel rather than only the selected replay decision window. That creates many backtest submissions/fills while the selected signal-session setup path has only two setups.

## Next required engineering task

Add explicit replay-window semantics to historical selected-period manifests and replay execution so that:

- Lookback rows are available for indicators/features.
- Trade simulation/reconciliation is scoped to the selected replay window.
- Setup, shadow, paper, backtest, and audit reconciliation compare the same decision universe.

Until that is fixed, selected-period dry-run replay qualification remains blocked.
